# Progress Log

`progress.md` is an append-only log of everything implemented in this
repository. After **every** task or work session — no matter how small —
append a new entry at the end of `progress.md` before finishing, using the
report format from `prompt.md` ("Working Style"): Implemented, Files
Changed, Database Changes, Environment Changes, Validation, Remaining
Issues, Recommended Next Step. Date each entry (`YYYY-MM-DD`). Never edit
or delete prior entries — only add new ones.

This is mandatory even if the user doesn't explicitly ask for it, and even
for changes that touch only docs/config.
